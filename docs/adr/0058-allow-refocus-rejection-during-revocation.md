# 撤销同步期间允许拒绝新的聚焦操作

宿主已失焦、页面尚未收到撤销通知时，现有消息不能可靠区分迟到旧请求与首次新操作。为控制来源追踪的复杂度，缩小 [0055](./0055-use-one-alt-pair-after-a-denied-focus-request.md) 的首次回点承诺：同步窗口内的新操作可以被拒绝，用户需要重新操作，不保证至多多点一次。保留浏览器原生光标、拖选与 Tab 行为，停止扩展完整 JavaScript 编辑接管。

[0050](./0050-hold-the-host-focus-for-the-composer.md) 的旧送键撤销和旧请求不得重新获取前台仍成立。这个取舍没有选定安全重开协议；重新开放入口仍须证明不会接纳迟到旧请求。请求编号、页面回执或等待一段时间本身不构成该证明，也不授权自动重试获取。

备选是保留第一次新操作必定成功的承诺，但需要继续建立具体动作来源机制。用户接受上述体验边界以缩小实现范围；产品实现和安全重开验收仍待完成。
