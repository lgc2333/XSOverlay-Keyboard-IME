# 组字串临时拼进 composer 输入框，提交后还原

组字串不再写 `placeholder`：浏览器只在输入框为空时显示占位文字，输入框已有内容时用户看不到编码。改为把组字串临时拼在输入框已有文字的光标处，光标跟在编码之后；提交或取消时还原原值与选区。组字串因此始终可见，位置也与原生输入法一致。

## Considered Options

- `placeholder` 独占：输入框为空时才可见，用户已有文字时看不到；放弃。
- 显示在候选栏：候选栏是候选的位置，编码挤在那里会被误认为候选；放弃。
- 临时拼进输入框再还原：采纳。

本 ADR 取代 [26-11-05-1](../handoffs/26-11-05-1_keyboard-ime.md) 第 6 节"组字串走 placeholder、`value` 不动"那条界面决定。那条只写在交接文档里，没有对应的 ADR，因此本文件不设 `amends` 关系。

## Consequences

- 组字期间输入框的 `value` 会临时包含编码，页面可能因此启用发送键；注入脚本在组字期间把它压回禁用。
- 还原依赖组字期间光标位置不变。接管期间按键不进输入框，实际风险是用户用射线点了输入框。
