# JIS 专用键在空闲与组字时都交给输入法

[0026](./0026-faithful-callbacks.md) 与 [0036](./0036-one-table-for-key-ownership.md) 在空闲时只接管字符键，组字时按键名映射控制键。[JIS 专用键](../../CONTEXT.md#按键)不一定产生字符，现有映射也不识别它们，因此空闲时漏接管，组字时会吞键。

composer 输入框有焦点时，具有有效原生键码的 JIS 专用键在空闲与组字时都交给组字宿主，由当前输入法决定转换、切换字符种类或忽略。按键身份沿用原生键码，不根据输入法名称或显示标签选择行为；已有组合键规则与空闲时普通编辑键的页面归属继续适用。

否决只补组字期间键名白名单的方案，它仍会漏掉空闲时的专用键。此决定不修正 XSOverlay 已经解析错误的键码，也不把全部控制键交给宿主；键码来源与真实送达仍需分别验证。
