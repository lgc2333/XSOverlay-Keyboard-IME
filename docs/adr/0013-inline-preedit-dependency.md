# 组字串依赖输入法的行内预编辑设置

[0006](./0006-composition-host.md) 定下的宿主能拿到候选与提交文本，但组字串只在输入法开启行内预编辑时才有内容。实测小狼毫关闭该设置时，组字期间读到的窗口文本时有时无、IMM 返回空或垃圾；开启后窗口文本与 GCS_COMPSTR 都稳定返回组字串。因此插件要求用户开启该设置，读不到时降级为只显示候选。

## Considered Options

- 自建 IMM32 客户窗口：约三百行代码，靠 WM_IME_COMPOSITION 读 GCS_COMPSTR 与 GCS_RESULTSTR，不依赖用户改配置。代价是多维护一套 IME 宿主，且要自己处理合成窗口定位。
- 只显示候选，放弃组字串：实现最简单，但双拼用户看不到自己输入的编码，回删只能盲删。
- 依赖输入法的行内预编辑设置，读不到就降级：采纳。

## Consequences

- 用户必须在输入法里开启行内预编辑；README 的运行要求已写明小狼毫对应的设置项。
- 插件必须检测并提示，不能静默降级成"没有组字串"。
- 将来若要摆脱这个依赖，改建 IMM32 客户窗口即可，[0006](./0006-composition-host.md) 里关于候选与喂键的结论不受影响。
