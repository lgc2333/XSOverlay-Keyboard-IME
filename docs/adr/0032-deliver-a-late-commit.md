# 提交晚于组字结束也要送达

[0026](./0026-faithful-callbacks.md) 规定「按键结束后输入法已不持有组字也结束会话」，为的是让 Esc 取消之后不挂住会话与前台。真机上这条还有一个次序没考虑到：输入法有时先报空组字串、后报提交。会话先按「已不持有组字」结束，随后到达的提交就被当成「会话外提交」丢弃，用户打的字没有上屏。

所以本决定：**提交无条件送达页面，不以会话还开着为前提。** 会话仍按原规则结束，只是不再用「会话开着」拦提交。

## Considered Options

- 维持「会话外提交一律丢弃」：丢掉的是本次组字唯一的答案，正是要修的故障；否决。
- 把结束推迟到提交到达时：Esc 取消没有提交可等，会话会挂住；否决。
- 会话照常结束，提交无条件送达：采纳。

## Consequences

- 会话外提交的兜底只剩页面的焦点检查：输入框不在焦点时写回被拒并记日志。
- 空提交（取消、Esc）不写回任何东西，与原行为一致。
