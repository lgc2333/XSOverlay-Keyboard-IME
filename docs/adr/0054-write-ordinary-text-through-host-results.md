# 普通文字只经宿主结果写回

普通文字由组字宿主的字符或提交结果写回，页面不再同时接收会自行插字的普通字符原生 down/up；未被输入法消费的编辑键与快捷键继续交给浏览器默认处理。用户要求文字与编辑行为正确，不要求逐个普通字符事件，因而否决为了保留这些事件而增加页面默认插入拦截路径。

该规则修订 [0026](./0026-faithful-callbacks.md) 的非组字字符路由，保留不读写输入法模式的约束。安装版 Vuplex 没有禁止字符默认插入的按键参数，结果与原生编辑混用还已有连续输入乱序反例，见[证据](../archived/notes/host-lifecycle.md#证据物理输入)；结果先于后续编辑及其反向次序都须验证，不能只按托管调用返回判定完成。快捷键产生的粘贴等文字由浏览器处理，不再补写一次相同文本；Enter 的正式发送衔接仍遵循 [0052](./0052-broadcast-chatbox-previews-and-keep-native-submission.md)。
