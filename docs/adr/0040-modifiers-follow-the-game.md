# 修饰键实时送到系统，粘滞与解除规则跟随 XSOverlay

[0038](./0038-latched-modifiers-follow-the-host.md) 由插件自己保持修饰键，并在 composer 输入框失焦时复位，这与 XSOverlay 原来的粘滞规则不同。改为实时把键盘页的 Shift、Ctrl、Alt 按下与抬起送到系统，由 XSOverlay 决定何时保持、何时解除，插件不再另设粘滞或失焦复位规则。

- 关闭键盘或释放键盘焦点时，沿用 XSOverlay 释放全部粘滞键与保持键的行为，系统中的按键同步抬起。
- 插件接管的普通按键也要完成 XSOverlay 原有的粘滞解除，不能因跳过 XSOverlay 处理而留下按住的修饰键。
- Caps 每按一次，向系统发送一次完整的按下与抬起，关闭键盘不改变系统锁定状态。
- 键盘页的 Win 只由 XSOverlay 记录，不单独送到系统；Win+空格送到系统，其余 Win 组合键吞掉，沿用 [0036](./0036-one-table-for-key-ownership.md) 的限制。VR 打字时误触组合键不应打开桌面窗口，单按或松开 Win 也不应弹出开始菜单。

否决仅把修饰键交回页面的做法：XSOverlay 在键盘页有焦点时只记录网页修饰键，不会向系统发送按下。也否决继续由插件自管粘滞：它重复了 XSOverlay 的规则，并改变了按键解除时机。本决定只修订 0036 与 0038 的修饰键处理，其余规则不在本决定范围内。
