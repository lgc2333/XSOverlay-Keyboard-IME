# 按语言栏附加图标的有无显示中英切换按钮

composer 输入框有焦点，且当前键盘输入项能在 Windows 输入指示器显示[语言栏附加图标](../../CONTEXT.md#界面)时，显示中英切换按钮。微软拼音应显示，美式键盘布局不显示。插件取不到图像不等于系统没有附加图标，不能因此隐藏按钮。

尽量复用输入法原图及原有视觉效果，包括透明度与单色图标的主题着色。返回字形时，WebView 用原始字符与对应系统图标字体显示；返回 `HICON` 时沿用现有图像路径。实在取不到原图，且已确认该输入项能显示附加图标时，使用固定占位。否决把图像提取成功作为显示条件的做法，它会隐藏微软拼音应有的切换入口；也不把首个无图标的系统菜单项当成输入模式项。

数据来源优先使用当前宿主的公开 TSF 输入模式项 `GUID_LBI_INPUTMODE`。公开模式项不存在时，允许用 `InputSwitch.dll` 的未公开 Shell 接口读取模式项并调用原生点击。这是[0028](./0028-mirror-the-ime-language-bar-item.md) 公开接口范围的明确例外，不按输入法名称选择路径。图像读取或转换失败不等于公开模式项不存在。

选定来源后，图像、可见状态与点击均使用该来源，切换键始终对应宿主当前输入项。否决将 Shell 作为所有输入法的首选：已有公开 TSF 来源时，直接读取宿主线程即可满足要求，使用私有接口会扩大 ABI 与前台状态依赖。

固定占位只替代图像，不补出点击入口。两条路径均没有可信原生点击入口时，按钮仍显示为 `disabled`；取消缩放动画，hover 不显示边框，非焦状态的视觉保持原样，不额外变暗。点击不触发任何行为，包括音效、前台切换与原生调用。原图也不可读时使用固定占位，切换输入项时仍清除上一项图像。明确没有附加图标的美式布局继续隐藏，composer 输入框失焦时沿用原有隐藏规则。

[0026](./0026-faithful-callbacks.md) 的模式约束与现有按键路由继续适用。

页面沿用 [0037](./0037-the-page-owns-the-composer-state.md) 的焦点管理与 [0046](./0046-place-the-switch-beside-left-alt.md) 的布局。切换输入项时清除旧图像，隐藏时恢复空格，键盘行宽不变。

2026-11-08 的实现验证确认 Shell 点击异步投递，成功返回与同 STA 消息屏障均不能稳定确定模式更新完成；重建对象也会引入旧状态。因此当前 Shell 路径只读原图或字形，显示为 disabled，公开 TSF 路径仍可原生点击。Shell 对象仅在宿主的前台租约内存活，并校验缓存的线程与窗口归属；后台保留宿主快照。已在 .NET 与 Unity Mono 的隔离宿主验证，兼容范围锁定为校验通过的系统 DLL，详见[适配说明](../notes/input-mode-shell.md)。其他版本与实际 VR 场景仍待验证。
