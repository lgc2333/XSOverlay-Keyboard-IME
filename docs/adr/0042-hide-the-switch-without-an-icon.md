# 没有可显示的语言栏图标时隐藏中英切换按钮

中英切换按钮只镜像输入法实际提供的语言栏项，composer 输入框有焦点且当前项有可显示图标时才出现。没有项或没有可显示图标时移除整个按钮，切换输入法时明确清除旧图标，避免留下上一输入法的按钮。

删除 [0028](./0028-mirror-the-ime-language-bar-item.md)、[0035](./0035-show-the-ime-only-while-the-composer-has-focus.md) 与 [0036](./0036-one-table-for-key-ownership.md) 的“中/英”备用字样，也删除退回首个无图标按钮的做法。仍按 0028 的通用规则选择带图标的语言栏项，不按输入法名字适配；取得或转换图标失败时记录失败，不把插件转换失败归为输入法没有提供图标。

页面仍按 [0037](./0037-the-page-owns-the-composer-state.md) 管理按钮的可见性与位置，显示条件增加当前图标可用，隐藏后空格原有区域可直接点击，键盘行宽不变。否决保留备用按钮的做法，它可能没有作用，也可能点击到其他语言栏项。
