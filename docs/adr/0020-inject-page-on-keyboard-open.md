# 键盘页在键盘打开时注入，不等第一次击键

脚本注入点从"接管第一次用到键盘页"改为"键盘打开时"，另外在组字宿主就绪后再试一次。候选栏是用户按键之前就该看到的东西，而且它会把键盘撑高一行；等到第一次击键才注入，键盘会在用户眼前突然变高。

## Considered Options

- 等第一次击键再注入，见 [0004](./0004-inject-page-script.md)：界面在按键后突变；放弃。
- 每帧检查键盘页是否出现：等于轮询，违反 [0005](./0005-event-driven.md)；放弃。
- 挂在游戏"设置键盘可见性"上，再加一次启动尝试：采纳。

## Consequences

- 注入发生在键盘打开那一刻，页面可能还没加载完；页面里"二次注入无害"的保护与失败重注入兜住这种情况。
- 这个补丁点与其他补丁一样在启动时按 owner 校验；游戏方法改名会让插件拒绝工作并写日志。
