# 以网页收到操作作为新聚焦请求的边界

为停止扩展跨 SteamVR、托管队列与浏览器的动作来源追踪，新的聚焦请求以键盘页实际收到明确点击、触摸或键盘导航为起点，不追溯物理按下时间。用户接受：撤销前产生、但在页面完成撤销同步并重新开放后才到达的原生输入，可以被当作新操作，重新获取前台。这是主动缩小安全承诺，不是证明旧输入已排空。

修订 [0050](./0050-hold-the-host-focus-for-the-composer.md) 与 [0058](./0058-allow-refocus-rejection-during-revocation.md) 的新旧边界：撤销前已生成的页面聚焦请求、旧资格下的按键与档案工作仍作废；窗口恢复、布局重建、脚本自动聚焦、状态报告及迟到答复不能生成新资格。新请求在实际页面事件入口固定文档、撤销代次与请求身份，延后发送也不重新标记。

0058 的同步期间拒绝与重新操作边界保留。保留浏览器原生光标、拖选与 Tab；不采用 CDP 输入替换或完整 JavaScript 编辑接管。备选是仍按更早的输入产生时刻拒绝所有旧动作，但需恢复已停止的来源机制调查。用户选择上述边界以控制实现复杂度。具体撤销确认与重开接线仍须验证，见[协议方案](../handoffs/archived-notes/foreground-refocus-protocol.md)；本决定不授权产品实现。
