# composer 聚焦期间由组字宿主持有电脑焦点

独立生产宿主对照确认，每键立即归还前台会使微软拼音和日语无输入，保留前台则能产生组字或普通字符，见[调查记录](../handoffs/26-11-08-1_roadmap-input-defects.md#独立宿主的前台归还对照)。`SendInput` 返回、队列暂空与组字结束均不能证明异步输入处理完成，因此不再按单键或组字会话决定归还前台的时刻。

composer 输入框聚焦期间，隐藏组字宿主持有电脑前台和键盘焦点，物理键盘也以 composer 为输入目标。聚焦时只尝试一次正常获取，失败时撤销本次聚焦并通知页面失焦，不等待、重试或合成恢复按键。组字结束、普通字符交付与修饰键释放不结束前台租约，结束组字会话与结束前台租约分开处理。

用户操作桌面使宿主失焦时，立即撤销该焦点期的送键资格，并同步通知键盘页使 composer 失焦。后续排队按键不得夺回前台，只有用户再次明确聚焦 composer 才能重新获取。页面主动失焦或关闭键盘页时也结束租约；只有宿主仍在前台时才归还旧窗口，用户已选中新前台时保留该窗口。

失焦收尾交给输入法和系统的默认行为。该路径不发送 Escape，不强制提交，不调用原生激活开关来代替窗口失焦。已观察到小狼毫不提交字符、微软拼音提交全拼，这些是当前配置的基线，不是按输入法实现的分支。输入法实际提交的文本仍应写回原 composer，不自动重新聚焦；没有提交时不把组字串当作提交文本。

本决定修订 [0022](./0022-ingameime-host.md)、[0026](./0026-faithful-callbacks.md) 的前台寿命，以及 [0027](./0027-cancel-composition-on-caret-move.md)、[0034](./0034-a-rebuilt-composer-is-not-a-blur.md)、[0041](./0041-no-recovery-for-native-ime-results.md) 的失焦 Escape 规则。[0037](./0037-the-page-owns-the-composer-state.md) 的页面状态还须响应宿主真实失焦；光标移动、清空等编辑动作的取消与页面重建不算失焦的规则保留。

否决继续按单键短暂持有前台：当前没有可靠完成契约。实现前先验证物理文字、编辑键、快捷键与迟到提交，检查宿主和 Vuplex 双路输入、快速重新聚焦及关闭页面的归属。原生线程立即撤销资格，页面经 Unity 与 Vuplex 更新；同步失焦不要求阻塞窗口过程等待 DOM。实际 VR 边界仍须集中验收，[0014](./0014-vr-session-scope.md) 的支持范围不变。
