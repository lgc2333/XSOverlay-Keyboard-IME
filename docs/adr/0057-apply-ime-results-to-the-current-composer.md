# 输入法结果按交付时的当前 composer 处理

为把迟到结果始终交回原目标，[0053](./0053-retain-the-native-document-for-the-composer-target.md) 要求保留目标文档，并贯穿原生宿主、Unity 队列与页面维护目标身份、重建关联及回收边界。用户认为实现过于曲折、复杂度不值得，决定放弃这条路线；保留旧决策与实验记录，不将取舍写成技术上不可行。

组字串、候选和已提交文本只交给结果处理时存在、有效且聚焦的当前 composer；提交写入它的当前选区。否则丢弃，不缓存到再次聚焦，不追溯原页面、输入目标、焦点期或历史插入位置。接受重新聚焦后，旧结果可能影响当前组字、候选或正文；不再识别并隔离这类迟到结果。

本决定取代 0053，并修订 [0050](./0050-hold-the-host-focus-for-the-composer.md) 中「实际提交仍写回原 composer」的要求。0050 的焦点安全规则保留：真实失焦立即撤销旧送键资格，旧排队按键及旧聚焦请求不得重新获取前台。结果可交付不代表恢复送键资格；[0054](./0054-write-ordinary-text-through-host-results.md) 的文字通道与 [0056](./0056-show-preedit-in-a-composer-tab.md) 的显示方式保留。

不再仅为保全迟到结果而要求按逻辑目标保留原生文档。丢弃只指不更新页面，必要的原生清理和资源释放仍须完成；本决定不选择文档销毁方案、存储后端或线程数量，也不表示已完成产品实现。
