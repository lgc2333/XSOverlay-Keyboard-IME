# 插件转交用户操作，不补救输入法的原生结果

切换输入法时丢弃组字、提交原始编码或没有提交，都按输入法实际结果处理。插件沿用 [0026](./0026-faithful-callbacks.md) 的忠实回报原则，不替输入法补回车、空格、选候选或重放按键，也不等待它给出插件期望的结果。[0016](./0016-key-interception-point.md) 中把未提交组字串当作文本写回的规则不再适用。

- 删除启动时的 8 秒等待、合成 Alt、前台重试、切换后的 400 毫秒等待与下拉框的忙碌提示。前台只尝试一次正常切换，失败时记录并停止本次送键，不补发或重试。
- 输入法名字与图标在用户操作、语言变化与后续按键时刷新，不定时等待切换稳定，接受显示可能到下一次按键才更新的代价。这修订了 [0036](./0036-one-table-for-key-ownership.md) 与 [0038](./0038-latched-modifiers-follow-the-host.md) 的切换后等待规则。
- 保留用户移动光标、清空、离开 composer 输入框或关闭键盘时触发的取消，仍走 [0027](./0027-cancel-composition-on-caret-move.md) 的 Escape 路径；切换输入法本身不额外触发取消。
- 保留 [0037](./0037-the-page-owns-the-composer-state.md) 的 60 毫秒失焦判断等待，它用于避免把页面重建误当成用户离开，不用于等待输入法状态。

否决为保住组字或提前刷新显示而补按键、等待与重试的做法，它改变了输入法原有的结果，并增加了插件自行安排输入顺序的规则。
