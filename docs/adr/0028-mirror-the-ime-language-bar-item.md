# 中英切换按钮镜像输入法的语言栏项，按下即按它

VR 里没有中英切换入口，新输入上下文一律从英文开始，所以打不出中文。而 [0026](./0026-faithful-callbacks.md) 禁止插件判定或写入中英状态：状态属于用户。

本决定：**在键盘布局里插一个键，位置在空格左侧，键上画的是输入法自己那个语言栏项的图标（也就是 Windows 输入指示器画的同一个图标），按下时调用该语言栏项自己的点击入口。** 键宽取自空格，从空格扣掉等宽，布局总长不变；这与 [0012](./0012-synthesized-modifier-key.md) 原本的位置一致，只是不必改布局文件，页面每次重建后重新插入即可。 插件不读也不写任何模式，切换由输入法自己的代码完成。公开接口只有 TSF 的 `ITfLangBarItemMgr` 枚举、`ITfLangBarItemButton::GetIcon` 与 `OnClick`。

## Considered Options

- 送一次 Shift 给宿主窗口：小狼毫在非组字时把 Shift 当切换键，实测可用。但切换键由输入法配置决定，改了键位的输入法就失效；而且是"插件替用户按了一个键"，没有图可以显示状态。否决。
- 写 TSF 的转换模式隔间：标准输入法认这个隔间，小狼毫不认，它只在 `KEYBOARD_OPENCLOSE` 隔间被外部写入时取反自己的状态。为它单独补一条写入就是按输入法适配，违反仓库规则。实测 `ImmSetConversionStatus` 写不动小狼毫，否决。
- 镜像通知区托盘图标并模拟点击：Windows 11 的输入指示器不是通知区图标，托盘里没有它；任务栏自动隐藏时托盘工具条连枚举都取不到，而取它的像素与点它都要按具体输入法找图标。否决。
- 从输入法注册的 ICO 里取更大的一帧：图标文件路径只存在输入法自己的注册信息里，取它就得按输入法适配；而且 `GetIcon` 给的就是输入指示器当前显示的那一张，比它更大没有意义。否决。
- 镜像语言栏项并调用它的 `OnClick`：图标与点击都是 TSF 公开接口，输入法有没有这个项、画成什么样由输入法决定；采纳。

## Consequences

- 挑项的规则是「能画出图标」：系统自带的「语言 / 更正 / 键盘 / 帮助」四项都画不出图标，输入法那个输入模式按钮画得出。这条规则不认输入法的名字，也不认项的描述。
- 输入法若不添加带图标的语言栏项，按钮退化为「中/英」字样，按下仍然可用。
- 图标尺寸随 DPI 走：输入法按 `SM_CXSMICON` 加载 ICO，100% 时 16×16，150% 时 24×24。页面按原始像素画，再用 `image-rendering: pixelated` 最近邻放大，符合"过小就放大"的要求。
- 图标变化靠宿主线程每 400 毫秒读一次、比对指纹后推送；输入法改图不必有回调，代价是最大 400 毫秒的延迟。
- 按下的效果由输入法决定：有的输入法会忽略这次点击。插件只记录返回值，不兜底。
- 与 [0018](./0018-candidate-bar-display-only.md) 的"只显示"不冲突：候选仍然不可点，可点的只有这一个输入法自己的开关。
- 这个键按下时复刻页面自己的缩放动画与敲击音。页面的音效实例留在闭包里：`keyboard.js` 只导出 `setLayout`，播放函数与动画函数既不导出也不挂到 `window`，注入脚本取不到，改写 `StreamingAssets` 又会被游戏更新覆盖。所以按数据复用（音效包名、包设置文件、音量、音高、WebAudio 播放链），按行为复刻那十几行控制流：页面改数据我们跟着变，页面改逻辑我们不会跟。
- 页面还没放过任何键时没有音效包可查，按键保持安静；这与页面关掉打字音效时的表现一致。
- 这个键必须带 `key` 类：键盘页的射线命中只认 `.key`、`.keyboard-control`、`.dropdown-button`、`.dropdown-item`，放在候选栏里的控件在 VR 里点不到。
- 真机 VR 内尚未验证；控制台探针已跑通（按一下按钮后组字并提交「你好」，图标同时变化）。
