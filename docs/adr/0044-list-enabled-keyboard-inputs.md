# 下拉框列出用户启用的键盘输入项

[0039](./0039-switch-imes-from-the-bar.md) 只枚举输入法档案，既漏掉普通美式键盘布局，也纳入了用户未启用的档案。下拉框改为列出所有语言下用户启用的[键盘输入项](../../CONTEXT.md#组字)，包含键盘类输入法档案和普通键盘布局，排除语音、手写等其他文本服务。

使用 `ITfInputProcessorProfileMgr.EnumProfiles` 的类型、类别与 enabled 标志筛选，模型保留激活所需的档案标识或键盘布局句柄。枚举、显示和激活覆盖同一类条目，插件不为显示或切换条目而启用它。

否决继续只列 TIP 档案，它无法让用户选择已启用的美式键盘布局。语言名、多语言显示与菜单交互沿用 0039。
