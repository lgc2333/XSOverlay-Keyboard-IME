# 中英切换按钮占左 Alt 右侧的 1u，空格等量让位

修改 [0037](./0037-the-page-owns-the-composer-state.md) 的覆盖布局：中英切换按钮紧接左 Alt，占 [1u](../../CONTEXT.md#布局)，高度与普通字符键一致，外观及悬停、按压反馈跟随左 Alt。沿用原生边距，不增加右间距；输入法原图标居中、等比例平滑缩放。显示条件继续遵循 [0042](./0042-hide-the-switch-without-an-icon.md)。

显示时从空格扣除按钮宽度及其两侧边距，隐藏时恢复原空格宽度。页面在同一任务内完成按钮增减与空格改宽，尺寸及边距即时变化，保留原生颜色、阴影与缩放动画。整块键盘宽度、主键区边界与左右 Ctrl 坐标必须保持原样，原回车形状与高度不变。

否决覆盖空格、额外增加右间距及只插入按钮的方案：它们分别覆盖原有按键区域、改变原生键距或挤动右侧按键。产品脚本在安装版隔离页面覆盖 ANSI、ISO、JIS 与三种布局格式，逐帧测量显示、隐藏、悬停和按压，总宽度及左右 Ctrl 坐标变化均为 0px；当前原生键面间距为 4px。深浅样例配色均跟随 Alt，真实 VR 验收仍待完成。
