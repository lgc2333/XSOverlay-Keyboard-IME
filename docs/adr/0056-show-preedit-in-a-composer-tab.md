# 组字独立显示在正文外容器上沿

组字串显示在正文深色外容器上沿的标签中，正文 `input.value` 只保存已提交文本；显示和撤下不改正文值或选区，以保留原生撤销。临时拼入正文再还原会破坏后续撤销，证据见[迟到提交](../archived/notes/late-commit.md#页面侧)，因此不再采用 [0019](0019-inline-preedit-in-composer.md) 的显示方式。

标签从外容器左端缩进 10px，高 34px，上圆角、下平边，底色与深色容器一致；文字为次要灰色 `#bfbfbf`，无下划线，光标使用 accent。内部 padding 左 10px、右 11px，固定保留 1px 光标宽度；整段文字保持同一排版，光标独立绘制，移动光标不改变标签宽度或两侧 padding，长串只在内容区滚动与裁切。

键盘内部顶部常驻 26px 净空，显示和撤下组字都不改变工具栏、候选与按键位置，也不改变键盘总高度。原型总高 498px 是当前布局的验证基准，宿主缩放和 VR 尺寸同步仍须验收。
