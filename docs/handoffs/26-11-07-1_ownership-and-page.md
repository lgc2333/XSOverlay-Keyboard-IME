# 按键归属、composer 状态与输入法下拉（2026-11-07）

接续 [26-11-06-11](./26-11-06-11_faithful-callbacks.md)。这一轮把路线图「当前阶段待解决」的六条逐条落到代码，并补上「未实现」的两条。控制台探针与页面 e2e 都通过，真机 VR 复测未做。

## 现状一句话

按键归属变成一张表，粘滞修饰键回到页面，切换输入法前先上屏；页面自己拥有 composer 的焦点、几何与取消，候选栏能滚动、能选输入法。真机还剩一轮复测。

## 决定

- [0036](../adr/0036-one-table-for-key-ownership.md)：归属只有四个结论（页面／吞掉／输入法／系统），按下形态建模成 Standard/Sticky/Toggle。
- [0037](../adr/0037-the-page-owns-the-composer-state.md)：几何与可见性归页面；组字期间的值与光标归输入法；取消只有一条路径且没有静默出口。
- [0038](../adr/0038-latched-modifiers-follow-the-host.md)：Sticky/Toggle 一律留在页面（这样组字中也能打大写）；切输入法前单独送一次 Enter，隔 60 毫秒再切，期间不还前台。
- [0039](../adr/0039-switch-imes-from-the-bar.md)：下拉框列当前语言的 TSF 档案，用户选中即在本线程激活。

## 本轮实现

- 归属表与按下形态；Win+空格 交给系统，切换后隔 400 毫秒重读输入法与图标，图标缺失时页面退回自带字形。
- 取消不再跨线程预判；档案切换、语言栏按钮、Win+空格 三个切换动作共用「先上屏、再切换、留住前台」的事务。
- 页面：切换键绝对定位覆盖空格左端，不参与行排版；焦点即时生效；视图失活算失焦；组字期间的值／光标被外部改动即取消，且外部写下的值优先。
- 页面：重建输入框时组字跟着搬过去（已带组字串就只接管期望值，是原值才重写，否则取消）；写回早于组字结束时先收组字串再插入。
- 候选栏：活跃候选按最短距离滚进可见区，溢出一侧才渐隐。
- 输入法下拉框：插件列档案并发活动位置，页面画浮层、按位置勾选当前项。

## 验证

- 单测 55 个：归属表、按下形态、消息解析、状态载荷。
- 页面 e2e（无头 Chromium + 真实键盘页 + mock 宿主）连跑两次通过：切换键挂载/卸载、行宽零变化、光标与清空各取消一次、组字翻转不误取消、重建期组字存活、无行内预编辑不自我取消、写回交错、连点清空、下拉框开合与选项回传。
- 聚焦时间线：逐帧采样，聚焦与失焦全程行宽恒为 1152.52、漂移 0，切换键在焦点事件的同一任务里挂上且始终只有一个。
- 控制台探针 12 个场景回归：两次组字、数字选候选、翻页、回车原始编码、Esc 取消、退格、标点、左方向、Tab 分段、首键数字、零间隔快打，输出与既有预期一致。
- 游戏内注入冒烟：插件加载、页面脚本注入、按键进闸门（英文直通态）；组字态无法在外部制造。

## 未定

- 组字中切中英是否只是 Rime 自身行为。已按「先上屏再切」处理，真机复测后才能定论。
- ChatBox 实时预览：实现并验证过页面侧发送（同一 API 模块、同一条连接），但游戏的 OSC 服务拒绝空白文本，预览收不回去，且与 0011「不复制发送职责」冲突；已撤回。
- 60 毫秒失焦结算在卡帧时仍可能误取消；更精确的判据需要真机观察页面重建的时序。
- Win+空格 会让整个桌面的输入法跟着换；这是接受了的代价，但真机上「快速切换」的手感还没验。
- VRChat ChatBox：发文本的接口已知，页面可以用动态 import 拿到游戏自己的 api 模块；「正在输入」没有公共入口。

## 环境要点

- 游戏内注入走 XSOverlay 自己的 websocket（42070）：`Keyboard` 开浮层、`RequestKeyboardInputFocus` 拿游戏侧焦点、`SendKeyboardEvent` 送键；页面 composer 的 DOM 焦点仍需 VR 里点一下。
- 拒绝日志有 2 秒节流，连续注入时看不到每次拒绝。
- 部署：先停游戏（脚本可直停），`dotnet build -c Release -p:DeployToGame=true`，再 `steam.exe -applaunch 1173510`。
