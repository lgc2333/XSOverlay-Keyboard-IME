# 输入法列表顺序

页面按宿主给出的次序显示，顺序由 [ImeProfiles.ListChoices](../../XSOverlayKeyboardIme/Ime/ImeProfiles.cs) 决定。该函数原先每次先枚举当前语言，再枚举其他语言，[candidate-bar](../../web/src/candidate-bar.ts) 沿用收到的次序。

目标：尽量维持系统枚举顺序，切换只改变选中标记。不新增固定排序，也不缓存自定义顺序。

## 已实现

- 从 `ListChoices` 删除当前语言优先分支。
- 按 `GetLanguageList` 的次序枚举每种语言的 `EnumProfiles`，保留原有类型过滤。
- 每次刷新读取系统列表，选中项按档案身份匹配，不按名称排序。

## 证据

- 独立 STA 把线程语言依次切到中文、英文与日语，前后身份序列一致，切换只改变选中标记。
- 部署版本仍是旧基线（当前语言在前），不能用于验收该修复。

## 验收

- 同语言切换与跨语言切换前后的档案身份序列；系统枚举不变时，页面顺序必须不变。
- 真实页面核对顺序与选中项。
