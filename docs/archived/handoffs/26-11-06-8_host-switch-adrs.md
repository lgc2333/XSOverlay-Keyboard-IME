# 宿主替换的 ADR 决策与输入法模式验证（2026-11-06）

接续 [26-11-06-7](./26-11-06-7_ingameime-validation.md)。这一轮只做决策与验证，代码未改动。验证探针是临时程序，未入库。

## 结论

- 新增 ADR 0022、0023、0024、0025；0003、0006、0015 标为 `superseded`。
- 0015 的机制被实测**证伪**：那个隔间是翻转开关，不是设定值。已由 0025 取代。
- 0014 保留，属于预期行为：喂键仍走全局注入，仍要求宿主窗口在前台。
- 0009 不动（其内容本就没实现）。0012 同样尚未落地。

## 输入法模式的实测

单进程内分四轮，每轮先写隔间再逐键输入 `nihc` 加空格：

| 轮次 | 写入值 | 隔间读回 | 行为                           |
| ---- | ------ | -------- | ------------------------------ |
| 1    | 0      | closed   | 组字，提交「你好」             |
| 2    | 0      | closed   | 原样直通，五个字符全是普通文本 |
| 3    | 1      | open     | 组字，提交「你好」             |
| 4    | 1      | open     | 原样直通                       |

同一个值连写两次，模式翻转两次。所以写入 `GUID_COMPARTMENT_KEYBOARD_OPENCLOSE` 是**翻转**，不是设定，无法用它「强制打开」输入法。

这解释了旧实现为什么看起来能用：本机默认英文，每次组字前写一次、结束写回一次，两次翻转正好推回原处。写漏或写多就翻车；用户本来在中文时会被翻成英文；异常退出没走到还原，模式会留在翻转后的状态。

另有三条实测：合成一次 Shift 能由直通变组字，但受输入法键位配置限制，只作降级兜底；模式回调可用，`AlphaNumeric` 表示会进组字、`Native` 表示原样直通，但回调是异步的，必须等它到达再判定；直通模式下按键以 `WM_CHAR` 落到宿主窗口，宿主得自己收集这些字符作为未组字文本。

## 四条新 ADR

- [0022](../../adr/0022-ingameime-host.md)：组字宿主改用 IngameIME。组字串、候选、提交、模式全部走回调；不再实现任何 TSF 接口，也不再读 IMM。
- [0023](../../adr/0023-dynamic-link-shim.md)：上游仓库作子模块，构建动态库，再套一层自有的 C 薄壳。动态链接是 LGPL 2.1 的要求；薄壳隔离 C++ ABI。
- [0024](../../adr/0024-managed-delegate-callbacks.md)：原生回调改用托管委托函数指针。回调里抛异常会以 `STATUS_FATAL_USER_CALLBACK_EXCEPTION` 直接杀进程。
- [0025](../../adr/0025-respect-ime-mode.md)：组字前读模式，只在读到直通时翻转一次，写与当前值相反的值，结束不还原。

## 目录重组

旧结构把线程、窗口、TSF、喂键、租约与页面全塞进 `Host/`，还让它反向依赖 `Game/` 与 `Page/`：宿主持有页面对象，又自己去查键盘 overlay。重组按职责切四层，并让宿主彻底不接触 Vuplex。

```text
XSOverlayKeyboardIme/
  KeyboardImePlugin.cs       入口：配置、补丁校验、启动宿主
  MainThreadDispatcher.cs    任意线程到 Unity 主线程的队列
  Game/                      与 XSOverlay 打交道的全部，含 Patches/
  Takeover/                  接管判定；纯数据，可单测
  Ime/                       组字宿主；不接触 Vuplex
  Page/                      组字显示与写回；只在 Unity 主线程跑
  Interop/                   原始声明，含薄壳的 P/Invoke
  Input/                     虚拟键码
  Diagnostics/               日志
```

搬迁要点：四个 Harmony 补丁集中到 `Game/Patches/`；`Host/` 拆成 `Ime/`（线程、窗口、薄壳、模式、喂键、租约）与根下的 `MainThreadDispatcher`；`Takeover/` 新增纯数据视图 `PageKey`，使接管判定进得了测试项目；`Page/KeyboardPage.cs` 自己查键盘页，宿主不再持有页面对象。

删除：自检三件、旧的组字会话状态机三件、`Sinks/`、`Candidates/`、`ImmTextReader`、对应的会话测例。组字串、候选、提交改由回调直接给出，这三类代码整体失去存在理由。
