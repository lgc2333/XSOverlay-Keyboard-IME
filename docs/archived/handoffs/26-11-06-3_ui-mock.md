## 在 XSOverlay 外渲染键盘页

`node temp/ui-mock/real/server/index.cjs` 起两个服务：静态 8741 服务 `temp/ui-mock/real`，假 WebSocket 8740（静态端口减一），连上后依次推送主题、设置、配置、状态、布局五条消息。

踩过的三个坑，下次直接避开：

1. 必须打开 `http://127.0.0.1:8741/UserInterface/Default/Keyboard/Keyboard.html`。开根路径 `/` 会让页内 `./js/...` 全部 404，页面全白且控制台不报错。
2. `WebSocketServer` 要监听全部接口（`host: '::'`）。只绑 `127.0.0.1` 时，Chrome 把 `localhost` 解析到 `::1` 就连不上，表现为页面不建任何节点。
3. 页面背景透明。截图前把 `body` 背景设成 `#1b1d20`，否则是白底。

`?ime=jp` 只换候选与输入法名，键区仍是 ANSI。要真的看到 JIS 键区，必须同时换布局数据：`LAYOUT=ja ROWS=jis node index.cjs`，它会把 `keyboardFormat` 改成 `Jis`、布局 id 改成 `00000411`、主键区换成 `jis` 行集。切出 JIS 后可核对一条已知事实：JIS 没有中英键，ANSI 有。截图在 `temp/ui-mock/shots/`。
