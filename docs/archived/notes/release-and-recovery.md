- XSOverlay 提权运行，普通 shell 停不掉它；从 Steam 客户端的库页面停止，再替换文件。
- 经 Steam 重启：`steam.exe -applaunch 1173510`。进程退出后 Steam 仍可能报应用在运行，早启动会失败；等 `HKCU\Software\Valve\Steam\Apps\1173510` 的 `Running` 报成 0 再启动。
