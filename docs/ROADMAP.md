# 路线图

## 已实现

- [x] 接管键盘页的按键，交给系统输入法组字。
- [x] 在输入框里显示组字串，在候选栏里显示候选。
- [x] 提交后把文本写回输入框，不自动发送。
- [x] 组字期间的按键由输入法处理，不会落到输入框上。
- [x] 输入法不在组字时，编辑键与组合键照旧交给键盘页，不吞键。
- [x] 候选栏显示当前输入法的名字。
- [x] VR 里切换中英：布局里空格左侧多一个键，键上画输入法自己的语言栏图标，按下即按它。见 [0028](./adr/0028-mirror-the-ime-language-bar-item.md)。

- [ ] 使用 Win+空格 切换输入法之后，当前状态没有及时同步给键盘，导致显示的还是前一个输入法的图标和信息
- [ ] 在组字时按下tab或方向键，键盘输入框中的光标不会移动，且选中一个候选之后，组字状态被清空，没有任何字上屏输入框。在组字中途时突然输入其他符号其他符号的行为正常。
- [ ] 组合键（如Ctrl+A全选）按下无效，当前行为是仅向输入框键入a，win+空格在输入框聚焦状态也是键入空格。这个需要探讨一下怎么处理
