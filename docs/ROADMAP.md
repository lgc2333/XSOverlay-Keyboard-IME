# 路线图

## 已实现

- [x] 接管键盘页的按键，交给系统输入法组字。
- [x] 在输入框里显示组字串，在候选栏里显示候选。
- [x] 提交后把文本写回输入框，不自动发送。
- [x] 组字期间的按键由输入法处理，不会落到输入框上。
- [x] 输入法不在组字时，编辑键与组合键照旧交给键盘页，不吞键。
- [x] 候选栏显示当前输入法的名字。

## 未实现

- [x] VR 里切换中英：布局里空格左侧多一个键，键上画输入法自己的语言栏图标，按下即按它。见 [0028](./adr/0028-mirror-the-ime-language-bar-item.md)。
- [ ] 组字期间用射线点了输入框，或者输入框失焦、键盘页关闭时，取消组字。目前组字会留在原处。
- [ ] 候选栏右侧的输入法下拉框：现在只显示输入法的名字，还不能在几个输入法之间切换。界面定稿见 [26-11-05-1](../handoffs/26-11-05-1_keyboard-ime.md)。
- [x] 在键盘布局里合成中英键：已由 [0028](./adr/0028-mirror-the-ime-language-bar-item.md) 取代 [0012](./adr/0012-synthesized-modifier-key.md)，不做。

## 待验证

- [ ] 英文状态下连续输入时，前台切换是否可感知。
