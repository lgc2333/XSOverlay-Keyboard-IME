# 路线图

## 已实现

- [x] 接管键盘页的按键，交给系统输入法组字。
- [x] 在输入框里显示组字串，在候选栏里显示候选。
- [x] 提交后把文本写回输入框，不自动发送。
- [x] 组字期间的按键由输入法处理，不会落到输入框上。
- [x] 输入法不在组字时，编辑键与组合键照旧交给键盘页，不吞键。
- [x] 候选栏显示当前输入法的名字。

## 未实现

- [ ] VR 里切换中英。中英由系统输入法决定，插件既不切换也不猜。桌面停在英文时，VR 里只能打英文。
- [ ] 组字期间用射线点了输入框，或者输入框失焦、键盘页关闭时，取消组字。目前组字会留在原处。
- [ ] 点选候选、翻页按钮与页码。暂不打算做，理由见「设计取舍」。
- [ ] 在键盘布局里合成中英键。

## 待验证

- [ ] 数字键选候选在 VR 里的手感。
- [ ] 连续快速输入时，组字会不会提前结束。
- [ ] 英文状态下连续输入时，前台切换是否可感知。
