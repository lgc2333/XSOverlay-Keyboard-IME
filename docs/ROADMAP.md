# 路线图

## 已实现

- [x] 接管键盘页的按键，交给系统输入法组字。
- [x] 在输入框里显示组字串，在候选栏里显示候选。
- [x] 提交后把文本写回输入框，不自动发送。
- [x] 组字期间的按键由输入法处理，不会落到输入框上。
- [x] 输入法不在组字时，编辑键与 Ctrl、Alt 组合照旧交给键盘页；Win 组合键由插件吞掉，不往输入框打字符。见 [0029](./adr/0029-modifiers-from-game-state.md)。
- [x] 候选栏显示当前输入法的名字。
- [x] VR 里切换中英：布局里空格左侧多一个键，键上画输入法自己的语言栏图标，按下即按它。见 [0028](./adr/0028-mirror-the-ime-language-bar-item.md)。
- [x] 组字线程跟随前台窗口的输入语言：Win+空格 切换之后，图标、名字与组字都跟上。见 [0030](./adr/0030-follow-the-foreground-language.md)。
- [x] 组字串的光标画在输入法报出的选区上，方向键的效果看得见。见 [0031](./adr/0031-preedit-selection-follows-the-ime.md)。
- [x] 分段组字：空格只转换光标前那一段，会话随组字结束而不是随空格结束。见 [0033](./adr/0033-end-the-session-with-the-composition.md)。
- [x] 提交晚于组字结束时照样送达页面，不再被当成「会话外提交」丢弃。见 [0032](./adr/0032-deliver-a-late-commit.md)。
- [x] 组字期间用射线点了输入框、输入框失焦、键盘页关闭时取消组字；页面重建输入框不算失焦。见 [0027](./adr/0027-cancel-composition-on-caret-move.md)、[0034](./adr/0034-a-rebuilt-composer-is-not-a-blur.md)。

## 待真机验证

- [ ] Win+空格 切换输入语言之后，键盘上的图标、名字与组字都跟上。
- [ ] 组字中途按方向键：光标跟着动，空格只转换光标前那一段，再按空格完整上屏。
- [ ] Ctrl+A 全选生效；Win+空格 不再往输入框打空格。
- [ ] 组字期间射线点输入框、输入框失焦、关闭键盘页都会取消组字。
- [ ] 键盘页重建输入框（切语言、按 Shift、CapsLock）不打断组字。
- [ ] 提交晚于组字结束时照样上屏：连续快打、回车提交、取消后立刻重打都不丢字。
